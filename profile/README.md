### Your van. Your smart home.

Lighting, heating, water, power: your entire vehicle at a glance. An open, modular smart home system powered by Home Assistant.

- **100 % local.** Everything runs in the vehicle. Your data stays there too.
- **No subscription, no account.** You pay once. Nothing to renew, nothing to switch off remotely.
- **Switches stay switches.** Button logic runs on the hardware itself — even when Home Assistant is off.
- **Set up without code.** Decide in Home Assistant which button switches which light.
- **Grows with your build.** Start small, add MODULEs when you need them.

### How it is built

| | |
|---|---|
| **HUB** | Runs Home Assistant and the vehicle network |
| **LINK** | Wired/wireless connection to the HUB, keeps local logic running |
| **MODULE** | Does the work: RELAY, SWITCH, INPUT, SENSE, DIM, CONNECT, GPIO |

**Open software, documented hardware.** The software is open source. For every board we
publish datasheet, schematic, 3D model and renderings.
